## 🚀 Мои проекты

### 01. Морской бой Online

**Многопользовательская браузерная игра для двух игроков.**

Классический «Морской бой» с современным интерфейсом и возможностью играть с другом по ссылке.

**Возможности:**
- Игровые комнаты и онлайн-синхронизация ходов.
- Расстановка кораблей перетаскиванием.
- Адаптивный интерфейс для компьютеров и смартфонов.
- Встроенный чат с уведомлениями.
- Приглашения на реванш и серия партий в одной комнате.
- Восстановление игровой сессии после переподключения.

**Технологии:** Next.js, React, TypeScript, Tailwind CSS, Supabase, PostgreSQL, Vercel.

🎮 **[Играть онлайн](https://sea-battle-ashen.vercel.app/)**
